# Glossary

Every Sofia and Intuition term in one place. "UI" is what users read; "code" is the name in the source and APIs when it differs.

## Intuition protocol

| Term              | Meaning                                                                                                                                                                                                 |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **TRUST**         | The native token of the Intuition chain (mainnet, chain id 1155). Positions are bought and sold in TRUST.                                                                                               |
| **Atom**          | An on-chain entity: a page, an account, a topic, a platform. Created from data pinned to IPFS; its id is derived from that data.                                                                        |
| **Triple**        | A claim `subject / predicate / object` between atoms, e.g. `I / recommends / <page>`. A triple is itself a term and can be the subject of another triple (nested).                                      |
| **term_id**       | The bytes32 id of an atom or a triple. The indexer's `atoms` have no `id` field.                                                                                                                        |
| **Vault**         | Every atom and triple has vaults (one per bonding curve). A **position** is a holding of shares in a vault.                                                                                             |
| **Counter vault** | The "against" side of a triple. Its id is computed from the triple id.                                                                                                                                  |
| **Bonding curve** | How a share's price moves with supply. **Curve 1** (linear): price stays flat — used for atoms, tags, platform pools. **Curve 2** (progressive): price rises as people join — used for the page market. |
| **MultiVault**    | Intuition's core contract holding every vault.                                                                                                                                                          |
| **Indexer**       | Intuition's GraphQL API (`mainnet.intuition.sh`), read through `@0xsofia/graphql`.                                                                                                                      |

## Sofia

| UI                                             | Code                                 | Meaning                                                                                                                                                                                             |
| ---------------------------------------------- | ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Recommend**                                  | support, `recommends`                | Taking a position for a page: a deposit on its claim `I / recommends / <page>`.                                                                                                                     |
| **Oppose** (Distrust in the extension)         | oppose, counter                      | A position on the counter vault of a page's claim.                                                                                                                                                  |
| **Page market**                                | page claim                           | The single claim per page, `I / recommends / <page>`, on curve 2. See [data-model.md](data-model.md).                                                                                               |
| **Tag**                                        | `in context of`, context             | Why a page is recommended or what it is about, attached to the claim: an intention tag (`for work`, `for learning`, `for fun`, `for inspiration`, `for buying`, `for music`) or a topic / category. |
| **Topic**, **category**                        | `SOFIA_TOPICS`, taxonomy             | Sofia's subject taxonomy (`@0xsofia/taxonomy`); a category rolls up to its topic.                                                                                                                   |
| **Platform**                                   | platform atom                        | A website or service with its own Sofia atom (YouTube, GitHub…), with a market of its own.                                                                                                          |
| **Platform pool**                              | `pp_user_percentage`                 | The share of an extension Recommend (10% by default, 0–80%) deposited on the page's platform atom, taken out of the stake.                                                                          |
| **Position**, **value**, **change**            | —                                    | What you hold; what you'd get back (pro rata of the vault's assets); value minus what you put in.                                                                                                   |
| **Exit**                                       | redeem                               | Selling a position back to the vault (exit fee applies).                                                                                                                                            |
| **Cart**                                       | `CartService`, `useCart`             | Pending Recommends, opposes, tags and exits, published in one transaction.                                                                                                                          |
| **Free Recommend**                             | sponsored write                      | A Recommend paid by Sofia's treasury through the write-relayer; the position is the user's. See [free-recommends.md](../features/free-recommends.md).                                               |
| **Second opinion**                             | opinion                              | A Recommend or Oppose on a page exactly one other account recommended — free, outside the quota.                                                                                                    |
| **Publish without popup**                      | delegation, session key              | Extension mode that signs with a scoped session key instead of a wallet popup. See [extension.md](../features/extension.md#publish-without-popup).                                                  |
| **SofiaFeeProxy**                              | proxy                                | Sofia's contract in front of MultiVault; takes a fixed fee + a percentage; every Sofia write goes through it.                                                                                       |
| **Credible account**                           | credibility > 0                      | An account with a positive composite trust score from the MCP trust engine.                                                                                                                         |
| **Reputation** (score per topic)               | `derivedReputation`                  | Sum of the credibility of the accounts that took a position after you on your claims in that topic. See [reputation.md](../features/reputation.md).                                                 |
| **Top Voices**                                 | leaderboard                          | The reputation ranking on Explore (reputation-api snapshot).                                                                                                                                        |
| **Spotters**                                   | `trendHunter`                        | The monthly game of finding pages early. See [spotters.md](../features/spotters.md).                                                                                                                |
| **Spotted page**                               | `call`                               | A page where you were among its first 3 recommenders, then ≥ 5 credible accounts followed within the month.                                                                                         |
| **Influence**                                  | `flair`                              | Sum of the credibility of the accounts that followed you onto pages where you were among the first 3.                                                                                               |
| **Spotted this month**                         | `earlySignals`                       | The month's best spotted pages.                                                                                                                                                                     |
| **Missions**                                   | `@0xsofia/quests`                    | Daily and weekly goals (Express 3, Sort your pages, Pioneer, Topic of the week) that earn free Recommends.                                                                                          |
| **Pages to sort**                              | sort queue                           | Pages waiting for a second opinion, on `/spotters`.                                                                                                                                                 |
| **Echoes** (label "Bookmark" in the extension) | intention groups                     | Per-domain groups of pages the extension tracked locally, with automatic levels.                                                                                                                    |
| **Collection**                                 | bookmarks                            | The extension's bookmark lists.                                                                                                                                                                     |
| **Circle**                                     | `MEMBER_OF`, group                   | A group of accounts (on-chain membership). Hidden behind a feature flag.                                                                                                                            |
| **Season** (nav)                               | alpha testers                        | The all-time ranking of Sofia proxy users on `/leaderboard`.                                                                                                                                        |
| **Streaks**                                    | streak                               | Consecutive UTC days with a deposit on Sofia's daily atoms.                                                                                                                                         |
| **Beta Season Pool**                           | `SEASON_POOL_TERM_ID`                | An ended pool vault; positions can still be withdrawn.                                                                                                                                              |
| **Legacy claims**                              | `visits for …`, `trusts`, `distrust` | The per-intention page claims used before the page market; still read, no longer created.                                                                                                           |
